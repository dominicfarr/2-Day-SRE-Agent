# pydantic-ai against a local Ollama model, not the Claude Agent SDK

Superseding ADR-0002. The runtime agent must run entirely on the local M1 machine with no cloud inference cost — this is a training system, and cost matters — which rules out the Claude Agent SDK, since it's built specifically around Anthropic's hosted models. We chose `pydantic-ai` instead: it's model-agnostic (works against Ollama's OpenAI-compatible endpoint, running `qwen3:8b` locally), has a native MCP client for reaching the toy system's MCP server, and gives schema-validated structured output for the RCA (cause/evidence/confidence/action) for free. Unlike the Agent SDK, it doesn't hide the tool-use loop behind a harness — we still write and control that loop — so nothing about this choice reduces the project's value as hands-on agent-building experience. Claude (Sonnet 5) still writes the code; only the deployed agent's own inference moved local.
